# DeepSeek 2027 Plan

一个 DSH bundle：给「开发者模式」预设加上管理员命令执行、桌面控制、持久 SSH、自建工具、
人格、图片展示，以及 12 级思考控制。

## 安装

```
plugin_manager install_bundle target=D:\ds2027poje\dsh-deepseek-2027
```

改动 Host 半部（`index.js`）后需重启 DSH Desktop；纯客户端改动刷新页面即可。

## 两半

| 半部 | 文件 | 作用 |
|---|---|---|
| Host（全局） | `index.js`、`levels.js` | 思考等级投影、请求增强、`/think`、`/deepseek2027`、`/servers` |
| 客户端 | `client.js` | 输入框等级滑块 + 重新注入按钮、设置页 |
| 预设（scoped） | `developer.js` | 开发者工具与操作手册 |

## 思考等级

L1–L5 由提示词深度与输出预算逐级增强；L6 起进入认识论：

| 等级 | 特征 |
|---|---|
| L6 | 多假设并行，用证据淘汰 |
| L7 | 穷举边界与失败模式 |
| L8 | 形式化推导，数字双向验算 |
| L9 | 对抗性构造：找出能推翻自己的输入 |
| L10 | 六阶段：构成问题 → 双表征 → 原语推导 → 反事实加压 → 量化不确定度 → 构造性论证 |
| L11 | L10 之上：先下注后推导、承重结论点名、逐条派反方、显式分级置信 |
| L12 | 多智能体集群：分析派给子智能体，代码与决策自己写 |

切换：输入框左侧滑块，或 `/think 1..12`、`/think auto`。

| 工具 | 作用 |
|---|---|
| `dev_admin` | 以管理员身份执行任意命令行 |
| `dev_desktop` | 鼠标、键盘、窗口、截图全套 |
| `dev_ssh` | 一个持久 SSH 会话 |
| `dev_tool` | 让 AI 自己定义工具并热加载 |
| `dev_persona` | 读写长期人格 |
| `dev_image` | 展示图片：已有文件 / SVG 绘图 / 图表 |

L12 的两个团队工具在低于 L12 时**不注册**，不是「不建议用」——工具不存在比规则更可靠。

## 自建工具

AI 用 `dev_tool` 的 `create` 声明一个工具：名称、描述、参数 schema、命令模板。
插件把它编译成注册表定义并**立即挂载**，下一步即可调用。

每个工具在 `_custom/` 留下两份文件：

- `<name>.json` — 定义（机器读）
- `<name>.md` — 使用说明（人读，也是 AI 自己写的备忘）

系统提示词里只放**索引**（名字 + 摘要 + md 绝对路径），不放全文：说明会无限增长，
全塞进提示词会挤占真正的任务空间。

```json
{
  "name": "disk_free",
  "description": "报告某个磁盘的剩余空间",
  "parameters": { "type": "object", "properties": { "drive": { "type": "string" } }, "required": ["drive"] },
  "command": "Get-PSDrive {{drive}} | Select-Object -ExpandProperty Free"
}
```

`{{参数}}` 每个值都插入为 PowerShell 单引号字面量（内部引号翻倍），所以参数无法注入 shell 操作符。
占位符缺失直接报错，不会静默填空值。

## 人格

`_persona/PERSONA.md`，上限 3000 tokens（写时强制，不截断）。

以 **required 运行时上下文**注入，不是 section：装配每步重读，且它从不进入消息日志——
压缩折叠的是消息，人格不是消息，所以不可能被压缩掉。

AI 可用 `dev_persona` 自己改写，或直接编辑文件。

## 分析员（L12）

AI 用 `dev_agent` 定义自己的专家：

```markdown
---
role: perf-hunter
---
你只找性能问题：热路径、重复 IO、无界循环。忽略可读性。

回报：1. 最慢的一处 2. 为什么慢 3. 改哪一行。
```

内置四个：`code-reader`、`evidence-hunter`、`adversary`、`design-critic`。

然后用 `dev_team` 的 `spawn` / `wait` 派活。

**分工是硬边界，不是建议**：

- 分析员只做分析、检索、评审
- 写代码、改文件、跑命令，以及所有决策，**只能由主智能体自己做**
- 委派入口会分类简报，含写文件或执行命令意图的直接拒绝
- 分析员在只读预设下启动，即使它想改也改不了

分析员跑在独立上下文里，用户看不到它们的报告，所以主智能体必须复述并给出证据。

## 远程服务器

设置页「远程服务器」填写地址、端口、用户名、密码，勾选允许的操作（读取/写入/执行）。
不配任何服务器时，一切在本机执行。已配置则所有读写执行走同一条 SSH 连接。

也可用 `/servers` 命令：`list`、`add`、`remove`、`default`、`test`。

## 图片

- `show` — 展示磁盘上已有图片（PNG/JPEG/WebP/GIF）
- `draw` — SVG 标记栅格化为 PNG（需要部署自带 `sharp`）
- `chart` — 柱状/折线/饼图，像素直绘，不依赖 SVG 渲染器

媒体类型从魔数嗅探，不看扩展名。SVG 里禁止 `<script>`、`on*` 属性、外部引用。

## 重新注入

输入框右侧按钮或 `/deepseek2027`：重跑 DSH 的 `systemPrompt.assemble()`，
把最新装配结果（全部提示词段、运行时上下文、工具签名、当前等级）作为一条消息重新交付。
